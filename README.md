## About

Hostel Room Booking System is a React application that allows students to view hostel rooms, check room details, book a room and cancel their booking.

## Features

- View all available rooms.
- Filter rooms by AC and Non-AC.
- View room details and facilities.
- Book and cancel rooms.
- Only one room can be booked at a time.
- View booking details.

## Technologies Used

- React.js
- JavaScript
- HTML
- CSS
- React Router
- Vite
